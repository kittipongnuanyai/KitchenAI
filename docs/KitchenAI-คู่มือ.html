ขอ Gemini API key (ฟรี) และทดลองยิงคำขอแรก

เป้าหมาย: มี API key ของตัวเอง และเห็นคำตอบจาก Gemini บนหน้าจอด้วย curl ก่อนเขียนแอป

ก่อนจะให้แอป "คุยกับ AI" ได้ เราต้องมี API key ซึ่งเป็นรหัสผ่านยาว ๆ ที่บอก Google ว่าคำขอนี้มาจากบัญชีของเรา Google ให้ใช้ Gemini ฟรีในปริมาณจำกัดต่อวัน (เพียงพอสำหรับทำแล็บนี้ทั้งเทอม) ไม่ต้องใส่บัตรเครดิต

1.1 สร้าง key ใน Google AI Studio

  1. เปิดเบราว์เซอร์ไปที่ https://aistudio.google.com/apikey แล้ว sign in ด้วยบัญชี Google (ใช้ Gmail ส่วนตัวได้ บัญชีมหาวิทยาลัยบางแห่งอาจถูกแอดมินปิดไว้ ถ้ากดสร้างไม่ได้ให้สลับบัญชี)
  2. ครั้งแรกจะมีหน้าให้ยอมรับข้อตกลง (Terms of Service) กดยอมรับ
  3. กดปุ่ม Create API key → ถ้าถามให้เลือกโปรเจกต์ ให้เลือก Create API key in new project หรือโปรเจกต์ที่ระบบสร้างให้ (ชื่อ Gemini API / Default)
  4. ระบบจะแสดง key ขึ้นต้นด้วย AIza ยาวประมาณ 39 ตัวอักษร กด Copy แล้ววางเก็บไว้ในที่ปลอดภัย เช่น ไฟล์ Notes ส่วนตัว (ยังไม่ต้องวางลงในโค้ด)
กติกาเรื่อง key — สำคัญมาก
  • key = เงินของคุณ ใครได้ key ไปก็ใช้โควตาแทนคุณได้ ห้ามโพสต์ในกลุ่ม ห้ามใส่ในสไลด์ ห้าม commit ขึ้น GitHub
  • แอปนี้ออกแบบให้ใส่ key ผ่านหน้า "ตั้งค่า" และเก็บไว้ในเครื่องเท่านั้น จึงไม่มี key อยู่ในโค้ดเลย
  • ถ้าเผลอหลุด ให้กลับไปที่ aistudio.google.com/apikey กด Delete key เดิมแล้วสร้างใหม่ ใช้เวลาไม่ถึงนาที
  • Google จำกัดโควตาฟรี "ต่อนาที" และ "ต่อวัน" (ดูตัวเลขปัจจุบันที่ aistudio.google.com/rate-limit) ถ้ากดถี่ ๆ จะได้ error 429 — รอสักครู่แล้วลองใหม่

1.2 ยิงคำขอแรกด้วย curl (ยังไม่ต้องใช้ Flutter)

เราจะคุยกับ Gemini ด้วยคำสั่ง curl ก่อน เพื่อให้เห็นว่า "API" ก็คือการส่ง JSON ไปที่ URL หนึ่ง แล้วได้ JSON กลับมา — แอป Flutter ของเราก็จะทำแบบเดียวกันเป๊ะ (Windows 10/11 มี curl ติดมาแล้ว เปิด PowerShell หรือ Terminal ใน Android Studio ก็ได้ · macOS เปิด Terminal)

macOS / Linux (แทน ใส่KEYของคุณ ด้วย key จริง):

curl "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash:generateContent" \
  -H "x-goog-api-key: ใส่KEYของคุณ" \
  -H "Content-Type: application/json" \
  -d '{"contents":[{"parts":[{"text":"มีไข่กับหมูสับ ทำอะไรกินได้บ้าง ตอบสั้นๆ"}]}]}'

Windows PowerShell (ต้องใช้ curl.exe เพราะ curl เฉย ๆ ใน PowerShell เป็นคำสั่งอื่น และต้องใส่ body ผ่านไฟล์เพื่อเลี่ยงปัญหาเครื่องหมายคำพูด):

# 1) สร้างไฟล์ body.json ด้วย Notepad ให้มีข้อความนี้ (บันทึกเป็น UTF-8)
{"contents":[{"parts":[{"text":"มีไข่กับหมูสับ ทำอะไรกินได้บ้าง ตอบสั้นๆ"}]}]}

# 2) รันใน PowerShell ที่โฟลเดอร์เดียวกับ body.json
curl.exe "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash:generateContent" -H "x-goog-api-key: ใส่KEYของคุณ" -H "Content-Type: application/json; charset=utf-8" --data-binary "@body.json"

ถ้าสำเร็จจะได้ JSON ก้อนใหญ่ หน้าตาประมาณนี้ (ตัดให้สั้น):

{
  "candidates": [
    {
      "content": {
        "parts": [ { "text": "ทำได้หลายเมนูเลยครับ เช่น\n1. ไข่เจียวหมูสับ ..." } ],
        "role": "model"
      },
      "finishReason": "STOP"
    }
  ],
  "usageMetadata": { "promptTokenCount": 21, "candidatesTokenCount": 180, "totalTokenCount": 201 },
  "modelVersion": "gemini-3.8-flash"
}
อ่าน JSON นี้ให้ออก — ทั้งแอปใช้แค่นี้
  • candidates[0].content.parts[0].text = ข้อความคำตอบ (คำตอบอาจแบ่งเป็นหลาย part ต้องเอามาต่อกัน)
  • finishReason = ทำไมถึงหยุดตอบ: STOP ปกติ · MAX_TOKENS ยาวเกินที่กำหนด · SAFETY ถูกบล็อก
  • usageMetadata = ใช้ไปกี่ token (หน่วยนับความยาวข้อความ ประมาณ 1 token ≈ 1–3 ตัวอักษรไทย) — ตัวเลขนี้คือสิ่งที่โควตานับ
  • ถ้าได้ {"error": {"code": 400, "message": "API key not valid..."}} แปลว่า key ผิด/คัดลอกไม่ครบ · 429 = ยิงถี่เกินโควตา
Checkpoint 1
  • มี API key เก็บไว้แล้ว และรู้ว่าจะไปลบ/สร้างใหม่ที่ไหน
  • curl ได้คำตอบภาษาไทยจาก Gemini (ถ่ายภาพหน้าจอผลลัพธ์ไว้ส่งงาน)
  • ชี้ได้ว่าข้อความคำตอบอยู่ตรงไหนของ JSON

เป้าหมาย: อ่าน/เขียน request และ response ของ generateContent ได้ทุกช่อง ก่อนลงมือเขียนโค้ด

Gemini มี REST API ชื่อ generateContent ทำงานแบบ "ส่ง JSON ไป ได้ JSON กลับ" ครั้งเดียวจบ (ไม่จำบทสนทนา — ถ้าอยากคุยต่อเนื่องต้องส่งประวัติไปเองทุกครั้ง ดูโจทย์ท้าทายข้อ B) URL มีรูปแบบคงที่:

POST https://generativelanguage.googleapis.com/v1beta/models/{ชื่อโมเดล}:generateContent
Header  x-goog-api-key: <API key>
Header  Content-Type: application/json

4.1 Request: สิ่งที่เราส่งไป

{
  "system_instruction": {                       // (ไม่บังคับ) บทบาท/กติกาที่ AI ต้องยึดตลอด
    "parts": [ { "text": "คุณคือเชฟอาหารไทย ตอบเป็นภาษาไทย ..." } ]
  },
  "contents": [                                 // บทสนทนา — แล็บนี้ส่งแค่ 1 ข้อความจากผู้ใช้
    {
      "role": "user",
      "parts": [                                // 1 ข้อความมีหลาย "ชิ้น" ได้: ข้อความ + รูป
        { "text": "ตอนนี้ฉันมี ไข่, หมูสับ ..." },
        { "inline_data": { "mime_type": "image/jpeg", "data": "<รูปเข้ารหัส base64>" } }
      ]
    }
  ],
  "generationConfig": {                         // ตัวเลือกการตอบ
    "temperature": 0.7,                         // 0 = ตอบนิ่ง ๆ เหมือนเดิม · 1-2 = สร้างสรรค์/สุ่มมากขึ้น
    "maxOutputTokens": 8192,                    // เพดานความยาวคำตอบ
    "responseMimeType": "application/json",     // (ไม่บังคับ) บังคับให้ตอบเป็น JSON ล้วน
    "responseSchema": { "type": "object", ... } // (ไม่บังคับ) โครงสร้าง JSON ที่ต้องการ
  }
}
ช่องเขียนอย่างไรทำไมสำคัญ
system_instructionข้อความบอกบทบาท กติกา ภาษา รูปแบบเขียนครั้งเดียวใช้กับทุกคำถาม ทำให้คำตอบนิ่งและเป็นแนวเดียวกัน (ของเราอยู่ใน prompts.dart)
contents[].parts[]อาร์เรย์ของ {text} หรือ {inline_data}ส่งรูปกับข้อความไปพร้อมกันได้ = multimodal · รูปต้องเป็น base64 ไม่ใช่ URL
temperature0–2งาน "ดูรูปแล้วบอกว่ามีอะไร" ใช้ค่าต่ำ (0.2) · งาน "คิดเมนู" ใช้ 0.7 ให้มีความหลากหลาย
responseSchemaJSON Schema แบบย่อ (type/properties/items/required/enum)ไม่ต้องเขียน regex แกะคำตอบ — AI ตอบตรงโครงสร้าง แปลงด้วย jsonDecode ได้เลย
ทำไม key ต้องอยู่ใน header ไม่ใช่ใน URL
  • เอกสารเก่าของ Google ใส่ ?key=... ท้าย URL ซึ่งใช้ได้ แต่ URL มักถูกบันทึกใน log ของเซิร์ฟเวอร์ proxy และประวัติต่าง ๆ ทำให้ key รั่วง่าย
  • header x-goog-api-key เป็นวิธีที่ Google แนะนำในปัจจุบัน และเทสต์ของเราตรวจว่า key ต้องไม่อยู่ใน URL

{

    {

HTTPbody ที่ได้สาเหตุที่พบบ่อยแอปควรบอกผู้ใช้ว่า
400{"error":{"code":400,"message":"API key not valid..."}}key ผิด / คัดลอกไม่ครบ / ถูกลบไปแล้วตรวจ key ที่หน้าตั้งค่า

5.3 ยิง HTTP POST และดักข้อผิดพลาดระดับเครือข่าย

lib/data/gemini_client.dart3/5
// 3) ยิง HTTP POST — key ส่งใน header ไม่ใส่ใน URL
http.Response res;
try {
  res = await _client
      .post(
        endpoint,
        headers: {'Content-Type': 'application/json', 'x-goog-api-key': apiKey},
        body: jsonEncode(body),
      )
      .timeout(kAiTimeout);
} on TimeoutException {
  throw AiException('AI ตอบช้าเกินไป (เกิน ${kAiTimeout.inSeconds} วินาที) ลองใหม่อีกครั้ง');
} on SocketException {
  throw AiException('เชื่อมต่ออินเทอร์เน็ตไม่ได้ ตรวจสอบ Wi-Fi หรือเน็ตมือถือ');
} on http.ClientException catch (e) {
  throw AiException('ส่งคำขอไม่สำเร็จ: ${e.message}');
}
  • jsonEncode(body) แปลง Map เป็นสตริง JSON · header Content-Type บอกว่า body เป็น JSON
  • .timeout(kAiTimeout) สำคัญมาก: AI ใช้เวลาตอบ 3–20 วินาที ถ้าเน็ตหลุดกลางทาง ไม่มี timeout แอปจะหมุนค้างตลอดกาล
  • ดัก 3 แบบ: หมดเวลา (TimeoutException จาก dart:async) · ไม่มีเน็ต (SocketException จาก dart:io) · อื่น ๆ ของ package http (http.ClientException) แล้วแปลงทั้งหมดเป็น AiException หน้าจอจึงดักแค่ชนิดเดียว

5.6 extractText(): เดินเข้าไปใน JSON ให้ปลอดภัย

lib/data/gemini_client.dartทั้งเมธอด
  static String extractText(Map<String, dynamic> json) {
    final feedback = json['promptFeedback'] as Map<String, dynamic>?;
    if (feedback?['blockReason'] != null) {
      throw AiException('AI ปฏิเสธคำถามนี้ (${feedback!['blockReason']}) ลองเปลี่ยนคำถาม');
    }
    final candidates = json['candidates'] as List<dynamic>?;
    if (candidates == null || candidates.isEmpty) {
      throw AiException('AI ไม่ได้ส่งคำตอบกลับมา');
    }
    final first = candidates.first as Map<String, dynamic>;
    final parts = (first['content']?['parts'] as List<dynamic>?) ?? const [];
    final text = parts
        .map((p) => (p as Map<String, dynamic>)['text'])
        .whereType<String>()
        .join();
    if (text.trim().isEmpty) {
      final reason = first['finishReason'] ?? 'ไม่ทราบสาเหตุ';
      throw AiException('AI ตอบกลับมาว่างเปล่า (finishReason: $reason)');
    }
    return text;
  }
}
อ่านโค้ด extractText ทีละบรรทัด
  • ทุกชั้นใช้ as ...? (nullable cast) แล้วเช็ก null — เพราะ JSON จาก AI ไม่มีการันตีว่าช่องไหนจะมี การ cast ตรง ๆ แบบ json['candidates'][0] จะพังทันทีที่ช่องหาย
  • first['content']?['parts'] — เครื่องหมาย ? หลัง ['content'] คือ null-aware index: ถ้า content เป็น null ให้ทั้งนิพจน์เป็น null แทนที่จะ crash
  • .whereType<String>() กรองเอาเฉพาะ part ที่เป็นข้อความ (part ชนิดอื่นเช่น thought/functionCall จะถูกข้าม) แล้ว .join() ต่อกัน
  • ลำดับการเช็ก: ถูกบล็อก → ไม่มี candidates → ข้อความว่าง แต่ละกรณีให้ข้อความ error ต่างกัน ผู้ใช้จะได้รู้ว่าควรทำอะไรต่อ

const String kChefSystemInstruction = '''
คุณคือเชฟอาหารไทยที่ใจดี ชอบสอนคนเริ่มทำอาหาร
- ตอบเป็นภาษาไทยที่อ่านง่าย ใช้ชื่อวัตถุดิบและหน่วยแบบไทย (ช้อนโต๊ะ, ถ้วย, กรัม)

- ถ้าวัตถุดิบไม่พอ ให้บอกชัดเจนว่าต้องซื้ออะไรเพิ่ม (ของพื้นฐานอย่างน้ำปลา น้ำตาล น้ำมัน กระเทียม ถือว่ามีอยู่แล้ว)
''';

/// สร้างคำถามสำหรับขอเมนูจากรายการวัตถุดิบ
String buildMenuPrompt(List<String> ingredients, {String? extra}) {
  final list = ingredients.map((e) => '- $e').join('\n');
  final condition = (extra == null || extra.trim().isEmpty) ? '' : '\nเงื่อนไขเพิ่มเติม: ${extra.trim()}';
  return '''
ตอนนี้ฉันมีวัตถุดิบดังนี้:
$list
$condition
ช่วยแนะนำเมนูที่ทำได้ 3 เมนู เรียงจากเมนูที่ใช้ของที่มีอยู่ครบที่สุดก่อน
แต่ละเมนูบอก: ชื่อเมนู, คำอธิบายสั้น ๆ, วัตถุดิบที่ใช้ (พร้อมปริมาณ), ของที่ต้องซื้อเพิ่ม, ขั้นตอนการทำทีละข้อ, เวลาที่ใช้, ความยาก
''';
}

  • กติกาเป็นข้อ ๆ อ่านง่ายกว่าย่อหน้ายาว ๆ ทั้งคนและ AI

/// ส่งรายการวัตถุดิบไปถาม AI
Future<void> _ask() async {
  if (_ingredients.isEmpty) {
    ScaffoldMessenger.of(context)
        .showSnackBar(const SnackBar(content: Text('ใส่วัตถุดิบอย่างน้อย 1 อย่างก่อน')));
    return;
  }
  setState(() {
    _loading = true;
    _error = null;
    _result = null;
  });
  try {
    final result = await widget.ai.suggestMenus(_ingredients, extra: _extraCtrl.text);
    if (!mounted) return;
    setState(() => _result = result);
  } on AiException catch (e) {
    if (!mounted) return;
    setState(() => _error = e.message);
  } catch (e) {
    // เช่น AI ตอบ JSON ผิดรูปแบบ → FormatException
    if (!mounted) return;
    setState(() => _error = 'อ่านคำตอบของ AI ไม่ได้: $e');
  } finally {
    if (mounted) setState(() => _loading = false);
  }
}
  • โครงเดียวกับ _test() ในหน้าตั้งค่า (Step 3.4) เพิ่ม catch (e) ท้ายสุดดักกรณี AI ตอบ JSON เพี้ยนจน jsonDecode พัง (FormatException) — เกิดได้แม้มี schema เช่นตอนคำตอบยาวเกิน maxOutputTokens แล้วถูกตัดกลางคัน
  • ส่วน build() ให้มาแล้ว: มันดูตัวแปร 3 ตัว _loading / _error / _result แล้วเลือกวาด spinner / ErrorBox / การ์ดเมนู ตามลำดับ — คุณแค่ทำให้ตัวแปร 3 ตัวนี้มีค่าถูกต้อง

7.1 เขียน _pickImage(): เอารูปเข้ามาและย่อก่อน

lib/screens/photo_screen.dartเฉลย
/// เปิดกล้องหรือคลังรูป แล้วย่อรูปให้เล็กลงก่อนส่ง (ประหยัดเน็ตและโควตา)
Future<void> _pickImage(ImageSource source) async {
  final XFile? file = await _picker.pickImage(
    source: source,
    maxWidth: 1024,
    maxHeight: 1024,
    imageQuality: 80,
  );
  if (file == null) return; // ผู้ใช้กดยกเลิก
  final bytes = await file.readAsBytes();
  setState(() {
    _imageBytes = bytes;
    _mimeType = file.mimeType ?? _guessMime(file.name);
    _result = null;
    _error = null;
  });
}
ทำไมต้องย่อรูป
  • กล้องมือถือถ่ายได้รูป 3–8 MB · base64 ทำให้ใหญ่ขึ้นอีก 33% · Gemini จำกัดคำขอทั้งก้อนที่ 20 MB และยิ่งใหญ่ยิ่งช้าและกินโควตา token
  • maxWidth/maxHeight: 1024 + imageQuality: 80 ให้รูป ~100–300 KB ซึ่ง AI ดูออกสบาย ๆ (หน้าจอแสดงขนาดที่จะส่งให้ดูใต้รูป)
  • readAsBytes() ได้ Uint8List เก็บไว้ใน state ทั้งแสดงผล (Image.memory) และส่งต่อโดยไม่ต้องอ่านไฟล์ซ้ำ
  • file.mimeType บน Android บางครั้งเป็น null จึงมี _guessMime เดาจากนามสกุล — Gemini ต้องการ mime_type ที่ถูกต้อง ไม่งั้นได้ 400

7.2 เขียน _analyze()

lib/screens/photo_screen.dartเฉลย
/// ส่งรูปไปให้ AI วิเคราะห์
Future<void> _analyze() async {
  final bytes = _imageBytes;
  if (bytes == null) return;
  setState(() {
    _loading = true;
    _error = null;
    _result = null;
  });
  try {
    final result = await widget.ai.analyzePhoto(bytes, mimeType: _mimeType);
    if (!mounted) return;
    setState(() => _result = result);
  } on AiException catch (e) {
    if (!mounted) return;
    setState(() => _error = e.message);
  } catch (e) {
    if (!mounted) return;
    setState(() => _error = 'อ่านคำตอบของ AI ไม่ได้: $e');
  } finally {
    if (mounted) setState(() => _loading = false);
  }
}

  /// https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash:generateContent
  Uri get endpoint => Uri.parse('$kGeminiBaseUrl/models/$model:generateContent');

  /// ส่งคำถามไป Gemini แล้วคืน "ข้อความตอบกลับ"
  ///
  /// - [prompt]            ข้อความที่ผู้ใช้ถาม
  /// - [systemInstruction] บทบาท/กติกาที่ให้ AI ยึด (ไม่บังคับ)
  /// - [imageBytes]        รูปภาพ (ไม่บังคับ) ส่งเป็น base64 ใน inline_data
  /// - [responseSchema]    ถ้ากำหนด จะบังคับให้ AI ตอบเป็น JSON ตามโครงสร้างนี้
  Future<String> generate({
    required String prompt,
    String? systemInstruction,
    Uint8List? imageBytes,
    String imageMimeType = 'image/jpeg',
    Map<String, dynamic>? responseSchema,
    double temperature = 0.7,
  }) async {
    if (apiKey.trim().isEmpty) {
      throw AiException('ยังไม่ได้ตั้งค่า API key — ไปที่หน้า "ตั้งค่า" ก่อน');
    }

    // 1) ประกอบ "ชิ้นส่วน" ของคำถาม: ข้อความ และรูป (ถ้ามี)
    final parts = <Map<String, dynamic>>[
      {'text': prompt},
      if (imageBytes != null)
        {
          'inline_data': {'mime_type': imageMimeType, 'data': base64Encode(imageBytes)},
        },
    ];

    // 2) ประกอบ body ตามรูปแบบที่ Gemini ต้องการ
    final body = <String, dynamic>{
      if (systemInstruction != null)
        'system_instruction': {
          'parts': [
            {'text': systemInstruction},
          ],
        },
      'contents': [
        {'role': 'user', 'parts': parts},
      ],
      'generationConfig': {
        'temperature': temperature,
        'maxOutputTokens': 8192,
        if (responseSchema != null) 'responseMimeType': 'application/json',
        if (responseSchema != null) 'responseSchema': responseSchema,
      },
    };

    // 3) ยิง HTTP POST — key ส่งใน header ไม่ใส่ใน URL
    http.Response res;
    try {
      res = await _client
          .post(
            endpoint,
            headers: {'Content-Type': 'application/json', 'x-goog-api-key': apiKey},
            body: jsonEncode(body),
          )
          .timeout(kAiTimeout);
    } on TimeoutException {
      throw AiException('AI ตอบช้าเกินไป (เกิน ${kAiTimeout.inSeconds} วินาที) ลองใหม่อีกครั้ง');
    } on SocketException {
      throw AiException('เชื่อมต่ออินเทอร์เน็ตไม่ได้ ตรวจสอบ Wi-Fi หรือเน็ตมือถือ');
    } on http.ClientException catch (e) {
      throw AiException('ส่งคำขอไม่สำเร็จ: ${e.message}');
    }

    // 4) ตรวจสถานะ HTTP
    if (res.statusCode != 200) {
      throw AiException(describeHttpError(res.statusCode, res.body), res.statusCode);
    }

    // 5) แกะข้อความออกจาก JSON ที่ตอบกลับ
    return extractText(jsonDecode(res.body) as Map<String, dynamic>);
  }

  /// แปลงรหัสสถานะ HTTP + body เป็นข้อความภาษาไทย
  static String describeHttpError(int status, String body) {
    String serverMessage = '';
    try {
      final json = jsonDecode(body) as Map<String, dynamic>;
      serverMessage = (json['error']?['message'] ?? '').toString();
    } catch (_) {}
    final detail = serverMessage.isEmpty ? '' : '\n($serverMessage)';
    switch (status) {
      case 400:
        if (serverMessage.contains('API key')) {
          return 'API key ไม่ถูกต้อง ตรวจสอบที่หน้า "ตั้งค่า"$detail';
        }
        return 'คำขอผิดรูปแบบ (400)$detail';
      case 401:
      case 403:
        return 'API key นี้ไม่มีสิทธิ์ใช้งาน ($status)$detail';
      case 404:
        return 'ไม่พบโมเดล "$kGeminiModel" — ชื่อโมเดลอาจเปลี่ยน ตรวจสอบใน ai_config.dart$detail';
      case 429:
        return 'ใช้โควตาฟรีเกินกำหนดชั่วคราว (429) รอสัก 1 นาทีแล้วลองใหม่$detail';
      case 500:
      case 503:
        return 'เซิร์ฟเวอร์ Gemini ขัดข้องชั่วคราว ($status) ลองใหม่อีกครั้ง$detail';
      default:
        return 'เกิดข้อผิดพลาด HTTP $status$detail';
    }
  }

  /// ดึงข้อความจาก JSON ตอบกลับของ Gemini
  ///
  /// รูปแบบ: { "candidates": [ { "content": { "parts": [ { "text": "..." } ] }, "finishReason": "STOP" } ] }
  static String extractText(Map<String, dynamic> json) {
    final feedback = json['promptFeedback'] as Map<String, dynamic>?;
    if (feedback?['blockReason'] != null) {
      throw AiException('AI ปฏิเสธคำถามนี้ (${feedback!['blockReason']}) ลองเปลี่ยนคำถาม');
    }
    final candidates = json['candidates'] as List<dynamic>?;
    if (candidates == null || candidates.isEmpty) {
      throw AiException('AI ไม่ได้ส่งคำตอบกลับมา');
    }
    final first = candidates.first as Map<String, dynamic>;
    final parts = (first['content']?['parts'] as List<dynamic>?) ?? const [];
    final text = parts
        .map((p) => (p as Map<String, dynamic>)['text'])
        .whereType<String>()
        .join();
    if (text.trim().isEmpty) {
      final reason = first['finishReason'] ?? 'ไม่ทราบสาเหตุ';
      throw AiException('AI ตอบกลับมาว่างเปล่า (finishReason: $reason)');
    }
    return text;
  }
}
